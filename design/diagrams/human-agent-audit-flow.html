04 · Human, assisted by planner

Authorize work

Choose a small batch of investigation questions and guarantees; apply the engagement's attacker charter; set methods, permissions, budget and stop conditions. Agents may then develop the attack sequences.

Hypotheses, property campaigns and scenarios share these gates; intake, exploration, revalidation and method evaluation have their own work authorization kinds. The scenario route is expanded below.

Every loop has an exit

Repeat for a named next check within an explicit allowance.

  • Evidence is ready for review
  • No useful authorized next step
  • Missing premise or blocked tool
  • Budget / retry limit reached
  • Pause, cancel or affected inputs

Stopping is a work outcome. It cannot turn incomplete work into a refutation or a safety claim.

The auditor can intervene at any time. Manual leads and tests enter the same evidence record.

Human attention: scope, relevant understanding, investigation questions and constraints, consequential clarifications, confirmation of interpretations, evidence decisions and release.

Agent iteration: provisional knowledge, scenarios, tests, challenge, refinement and drafting. Each inner loop shares its parent's limits.
