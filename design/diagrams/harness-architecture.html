Harness architecturePROPOSED · DEC-003

Follow authority from the auditor to local control, then execution. Two brokered routes describe external access.

01 · Human authority

Auditor interface

Side-by-side behavioral models, comparison gaps and evidence review. Auditor input develops DESIGNED behavior; the auditor approves batches, conclusions and report release.

Approved scope, budget and decisions
02 · Local control and records

Controller

Validates policy and revisions, schedules jobs, issues limited grants and commits decisions. Sole authority for canonical metadata.

Versioned engagement records

DESIGNED and IMPLEMENTED views; correspondence, comparison coverage and discrepancies; premises, jobs and human decisions.

Immutable evidence archive

Pinned sources, logs, traces, fixtures, artifacts and trusted receipts.

Context builder + change review

Both models + evidence → bounded context. Changes to either model → stale comparisons and dependent investigations.

Report snapshot + evaluation

Records and evidence → frozen report and metrics → auditor review.

Behavioral knowledge · Accepted process, DEC-006

DESIGNED

Documentation first → substantial auditor input + applicable evidence. Purpose, flows, states, stores, permissions and required outcomes.

IMPLEMENTED

Code + configuration + execution evidence. Actual guards, state effects, interactions, reachable outcomes and failure paths.

Compare meaning in both directions → correspondence + discrepancies + visible coverage → proposed investigations
Scoped jobs and read snapshots ↓ · Worker proposals and validated receipts return ↑
03 · Isolated execution

Agent roles

Seed both models and compare at every lens. Propose investigations of deviations and design weaknesses; use only approved context.

Tool broker + receipt collector

Validate tool requests → scoped execution. Collect raw output and artifacts → validated receipts.

Experiment and replay workers

Pinned analyzers, experiments and clean replay. Chain mutations occur only in an ephemeral local fork.

04 · Controlled external access

AI inference route

Agent → provider broker with scoped credentials → approved cloud AI provider. Only approved context leaves the workspace.

Chain data route

Ephemeral local fork → RPC policy gateway → approved archive RPC. Upstream methods are read-only.

Reading this diagram: layers show authority and boundaries; each card names its handoff. Brokers hold credentials outside workers. Information paths do not grant unrestricted file or network access.
